## 🚀 Choose Your Preferred Testing Method

### Option A: 1-Click Native Dual-Boot (No USB Required!)
Add Airlys directly to the official **Windows Boot Menu**. When you turn on your laptop, choose between Windows and Airlys!

1. Download or copy `airlys.iso` into this folder.
2. Right-click **`Airlys-DualBoot-Installer.bat`** and click **"Run as administrator"**.
3. Press **`Y`** to confirm.
4. Restart your laptop!
5. On the Windows blue boot menu, select **`Airlys Sovereign OS (Er. Adam Eehan)`**!
6. To go back to Windows, simply restart and select Windows.

### Option B: 1-Click Instant Window (No Laptop Restart Required!)
Test Airlys instantly right inside Windows in a high-speed hardware-accelerated 4K window without even rebooting your computer!

1. Double-click **`Run-Airlys-Instant.bat`**.
2. Airlys boots natively in 60 FPS TrueColor right on your desktop!

### Option C: VirtualBox / VMware (Classic Virtual Machine)
1. Open VirtualBox or VMware Workstation on Windows.
2. Create a new VM (`Type: Other`, `Version: Other/Unknown (64-bit)`, `RAM: 1024 MB`).
3. Attach `airlys.iso` to the virtual CD drive.
4. Click **Start** to run Airlys in full-screen mode!

## 🗑️ How to Uninstall
If you ever want to remove the dual-boot entry from Windows Boot Manager:
- Right-click `C:\Airlys\Uninstall-Airlys.bat` and choose **"Run as administrator"**.
- The boot menu entry and `C:\Airlys` folder are permanently and cleanly erased in 2 seconds.
