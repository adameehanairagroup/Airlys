## 📥 Getting Started

### 1. Download Airlys OS S1
Download the latest bootable ISO from the [Releases](https://github.com/adameehanairagroup/AirlysOS/releases) page.

### 2. Flash to USB Pendrive
* **On Windows**: Use [Rufus](https://rufus.ie/) (Select ISO, choose GPT / UEFI, DD image mode).
* **On Android**: Use [EtchDroid](https://etchdroid.app/) or Ventoy.
* **On Linux**: 
  ```bash
  sudo dd if=airlys-os-s1.iso of=/dev/sdX bs=4M status=progress oflag=sync
  ```

### 3. Boot & Enjoy
Plug the USB into your PC, power on, tap `F12` (or `F2` for BIOS), and select **Airlys OS S1**. SDDM will automatically load you into the live session!
